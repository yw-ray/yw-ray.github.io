Execution time by workload

Same chiplet-count layout and core-count colors as the bandwidth charts. Times come from the selected design's validated execution checks. Lower is faster.

Execution time (ms @ 1 GHz) = execution cycles / 1,000,000. These are simulated cycle counts converted at an assumed 1 GHz, not wall-clock search duration. Shared hardware is evaluated one workload at a time; each member retains its own chart. No summed or averaged group latency is implied.

Baseline 1/Baseline 2 are bandwidth-capacity baselines. This view shows execution time under the proposed individual/shared design; it does not invent separate baseline timings or imply bandwidth reduction equals a speedup. Reference limits and input provenance are included in the CSV.
