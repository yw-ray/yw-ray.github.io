C16 · DRAM placement (left / right vs middle of each side)

Asymmetric D2D with K = 3 rotation-only tiles on a 4 × 4 array. Updated 2026-10-19. Oracle results on pooled mappings.

3 / 5workloads win with left / right DRAM
3 / 5workloads win with mid-side DRAM

Rule

  • One asymmetric HW per workload serves b1, B4 and B16. A workload wins only when all three are ≥ 0%.
  • HW space: the K = 3 pinwheel groups, 64 B/cycle modules, Tx + Rx = 512 B/cycle on every link (343 designs). Design names list the group widths peri-ccw / outward / peri-cw / inner-ccw / inward / inner-cw.
  • Baseline: uniform 256 HW with the best of every mapping in the same pool. Mappings run on the whole array (no data-parallel split). Snake placements are excluded on both sides.
  • Both sides share the same mapping families. With left / right DRAM this includes the two-ring and own-half-DRAM mappings, searched on uniform and on the asymmetric HWs. With mid-side DRAM it includes six extra variants searched on HW A and on uniform.

Left / right (default)

Four controllers on the left and right edges. The busy direction on horizontal links points toward the centre in both halves (mirror symmetric), which rotation-only tile groups average out.

Middle of each side

One controller at the middle of each edge (90° rotation symmetric, matching the tile rotations). The perimeter ring shows a C8-like clockwise imbalance (68% vs 45% busy).

Reading

  • Both placements give three winners, but different ones. HW A (128-256-384-256-256-256, perimeter-only asymmetry) wins resnet50 in both and gpt_prefill with mid-side DRAM.
  • Left / right DRAM needed the two-ring mappings searched on the asymmetric HW itself. Before that search gpt_prefill (b1 −3.7%) and resnet50 (b1 −0.2%) missed.
  • transformer_cell misses in both (A: B4 −1.0%, B16 −0.5 to −1.9%). bert_block wins only with mid-side DRAM.
  • No single HW wins all five workloads yet in either placement.

Limits: oracle estimates on pooled mappings (96 to 578 mappings per workload), five workloads, default C16 resource model.
